# GHSMTA Portal Release Notes

## September 28, 2026

This release makes scheduling, shared files, school files, and portal communication easier to use across desktop and smaller screens.

### Chat and Portal Updates

- Messages can now be edited by the person who sent them.
- Users can reply directly to a message without losing the surrounding conversation.
- Selected attachments are shown before a message is sent.
- Attached PDF files can be previewed directly in chat.
- A new **Portal Updates** channel gives everyone one place to read official portal announcements.
- Only Owners can post in Portal Updates. Other users can read announcements without seeing the full portal user directory.

### Reference Documents and School Files

- Reference Documents now uses a familiar file-manager layout with folders, breadcrumbs, search, and drag-and-drop uploads.
- Owners can create folders and move documents between folders by dragging them.
- School Files now uses the same clean file-manager appearance.
- School users can drag files into their selected school and file type, while specialized uploads still collect any required details.
- Existing file access rules remain in place, so users only see documents shared with their role or school.

### Scheduling

- Advisory Members and Adjudicators now default to their booked schedule instead of the competition-track view.
- Waitlist filters and counts have been removed from staff schedule views.
- Schedule cards now show separate counts for Advisory Members, panel Adjudicators, Understudies, and Shadows.
- Each school can have one primary Advisory Member. Additional Advisory Members may join as Shadows when space is available.
- Staff assignment controls now prevent a panel, understudy, or shadow role from exceeding its allowed capacity.

### Dashboard

- Advisory Members and Adjudicators now see their adjudication dates directly on the dashboard.
- Each date card includes the school, production, time, location, and a shortcut to the adjudication workspace when available.

### Reliability and Security

- Chat editing, replies, attachments, and Portal Updates permissions are enforced by both the portal and the database.
- Portal Updates remains read-only for non-Owners, including replies and file uploads.
- The release passed automated tests, accessibility-oriented dialog checks, type checks, and a production build.
